# Code of conduct

ScopeSeed is a collaborative project. Be respectful, specific, and useful when discussing ideas, reviewing changes, or reporting problems.

## Expected behavior

- Discuss the work rather than attacking the person.
- Assume mistakes can be corrected, but do not dismiss repeated harmful behavior.
- Give actionable technical feedback where possible.
- Respect different experience levels and communication styles.
- Do not publish another person's private information.
- Do not use project spaces for harassment, discrimination, threats, or sexualized abuse.

## Enforcement

Repository maintainers may edit, hide, or remove content and may temporarily or permanently restrict participation when behavior makes the project unsafe or unusable for others.

If you need to report conduct privately, use a private repository contact method when available rather than posting sensitive details publicly.

This document is deliberately short and human-readable. Projects that need a formal community-governance process are welcome to propose a more detailed policy.
