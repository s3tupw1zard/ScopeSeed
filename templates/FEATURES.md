# Feature registry

This file lists accepted project features. ScopeSeed keeps features grouped by meaningful project categories and tracks their verified lifecycle state.

## Status meaning

- **Gapless** — the feature spec has no material unresolved ambiguity and passed independent verification.
- **Planned** — the Spec Kit planning/checklist/tasks/analyze path is complete.
- **Implemented** — implementation and the configured convergence/verification gate are complete.

Do not check a box solely because a similarly named file exists.
