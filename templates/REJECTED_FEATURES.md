# Rejected features

This file records features the project has deliberately decided not to include. The purpose is not to create a graveyard of every passing idea; it is to preserve decisions that future discovery would otherwise keep proposing.

|---|---|---|---|---|---|---|

## Reconsideration rule

A rejected feature may be raised again when:

- the user explicitly asks to reconsider it; or
- new verified evidence directly changes the assumptions behind the rejection.

When reconsidering, show the previous reason before changing the decision. If accepted later, keep the historical rejection row and note that it was superseded rather than erasing the decision history.
